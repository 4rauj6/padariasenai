## TECNOLOGIAS UTILIZADAS
Diante do que foi proposto pelo coordenador do projeto, o time de Front-End buscou utilizar tecnologias que tornassem o desenvolvimento mais rápido e viável para a conclusão do projeto.

* [HTML5](https://developer.mozilla.org/en-US/docs/Web/HTML) - Para criação do esqueleto do sistema.
* [CSS3](https://developer.mozilla.org/en-US/docs/Web/CSS) - Para estilização geral do sistema.
* [JAVASCRIPT](https://developer.mozilla.org/en-US/docs/Web/JavaScript) - Criação das funcionalidades e lógica do sistema.
* [FONTAWESOME](https://fontawesome.com/) - Ícones para estilizar o visual do sistema.
* [GOOGLE FONTS](https://fonts.google.com/) - Fontes para melhorar o visual do sistema.
